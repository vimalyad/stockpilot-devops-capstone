# StockPilot

Multi-warehouse inventory and procurement management, built for the Session 21 DevOps capstone.

Vimal Kumar Yadav · 24BCS10273

StockPilot manages products, suppliers, warehouse balances, reservations, stock transfers and purchase orders. PostgreSQL transactions protect the stock ledger; Redis and Celery process background inventory reports. The UI uses React and TypeScript; the API uses FastAPI, SQLAlchemy and Alembic.

Implementation and verification are in progress. See [the delivery checklist](docs/DELIVERY.md) for the current scope and outstanding execution evidence.
